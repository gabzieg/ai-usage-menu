# Security policy

## Supported versions

Security fixes are applied to the latest revision on the default branch until versioned releases are available.

## Reporting a vulnerability

Please do not publish an issue containing credentials, authentication artifacts, or a working exploit. Use GitHub's private vulnerability reporting feature for this repository. If private reporting is not enabled, open a minimal issue asking the maintainer for a private contact channel without including sensitive details.

Useful reports include the affected macOS and CLI versions, impact, reproduction steps with secrets removed, and a proposed mitigation if available.

## Scope

Issues involving command execution, executable discovery, pseudo-terminal parsing, credential exposure, unsafe logging, or unexpected provider actions are considered security relevant.
